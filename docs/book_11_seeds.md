# Book 11. Семена событий — разделы 11.1–11.4 (v0.1)

---

## 11.1. Философия: скрытность, вероятностность, условность

### 11.1.1. Назначение семян

> **Принцип:** семена событий — это **скрытые, вероятностные, отложенные последствия**. Они **не** происходят мгновенно. Они **зреют** — и игрок **не видит** их напрямую. Он видит только **симптомы** (слухи, знамения, странности).

### 11.1.2. Три ключевых принципа

| Принцип | Что это значит |
|---|---|
| **Скрытность** | Игрок **не видит** список семян. Только **симптомы**. |
| **Вероятностность** | Семя **может** сработать, а **может** рассосаться. |
| **Условность** | Семя срабатывает **только** при выполнении условий. |

### 11.1.3. Четыре дополнительных принципа

| Принцип | Что это значит |
|---|---|
| **Обнаружимость** | Игрок **может** раскрыть семя через расследование (G04). |
| **Предотвратимость** | Игрок **может** устранить семя действиями (деньги, внимание, репрессии). |
| **Ускорение** | Игрок **может** ускорить семя (если хочет, чтобы событие произошло). |
| **Взаимодействие** | Семена **могут** усиливать друг друга (бунт + мятеж генерала = гражданская война). |

### 11.1.4. Что семя **не** делает

| Что | Почему |
|---|---|
| **Не гарантирует событие** | Даже при выполнении условий есть вероятность, что семя не сработает |
| **Не показывает точные числа** | Игрок видит только симптомы, не цифры |
| **Не отменяет свободу воли игрока** | Игрок может предотвратить или ускорить семя |
| **Не превращает игру в «таймер обратного отсчёта»** | Семя может рассосаться само |

## 11.2. Структура семени

### 11.2.1. Поля семени (10)

| Поле | Описание | Пример |
|---|---|---|
| **ID** | Уникальный идентификатор | `bunt_campania_01` |
| **Тип** | Категория семени | Бунт, мятеж, заговор, скандал |
| **Цель** | Что/кто затронут | Провинция, NPC, фракция, игрок |
| **Источник** | Что создало семя | Отказ губернатору, унижение врага |
| **Условия** | Что должно быть true для проверки | Недовольство > 60, гарнизон < 30 |
| **Базовая вероятность** | Шанс срабатывания за ход (при выполнении условий) | 15% |
| **Модификаторы** | Что меняет вероятность | Память о бунтах (+5%), страх (−10%) |
| **Эффект** | Что происходит при срабатывании | Бунт в провинции |
| **Симптомы** | Что игрок может заметить | Слух «в Кампании неспокойно» |
| **Срок жизни** | Сколько ходов семя живёт | 10 ходов (потом «рассасывается») |

### 11.2.2. Пример структуры

```
{
  id: "bunt_campania_01",
  type: "bunt",
  target: "Campania",
  source: "player_refused_money",
  conditions: { dissatisfaction: 60, garrison: 30 },
  base_probability: 0.15,
  modifiers: { memory_bunt: 0.05, fear: -0.10 },
  effect: { bunt: true },
  symptoms: ["Слух: в Кампании неспокойно"],
  lifespan: 10
}
```

## 11.3. Стадии: холодное → тёплое → горячее → сработало / рассосалось

### 11.3.1. Пять стадий

| Стадия | Описание | Видимость для игрока |
|---|---|---|
| **Холодное** | Условия не выполнены, вероятность низкая | Невидимо (только случайные слухи) |
| **Тёплое** | Условия близки к выполнению, вероятность растёт | Слухи, знамения, странности |
| **Горячее** | Условия выполнены, вероятность высокая | Явные симптомы (доносы, предупреждения) |
| **Сработало** | Событие произошло | Письмо, диалог, кризис |
| **Рассосалось** | Условия не выполнены, срок истёк | Игрок может узнать постфактум |

### 11.3.2. Жизненный цикл

```
┌─────────────┐
│  СОЗДАНИЕ   │  ← действие игрока, бездействие, событие мира
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ ИНКУБАЦИЯ   │  ← семя «зреет», проверяются условия каждый ход
│ (холодное)  │
└──────┬──────┘
       │
       ▼ (условия выполняются)
┌─────────────┐
│  НАГРЕВ     │  ← вероятность растёт, появляются симптомы
│  (тёплое)   │
└──────┬──────┘
       │
       ▼ (условия выполнены + вероятность сработала)
┌─────────────┐
│ СРАБАТЫВАНИЕ│  ← событие происходит
└─────────────┘
       │
       ▼ (альтернатива)
┌─────────────┐
│ РАССАСЫВАНИЕ│  ← срок истёк, условия не выполнены
└─────────────┘
```

### 11.3.3. Проверка (каждый ход)

```
Вероятность срабатывания = Базовая вероятность
                         × (1 + Модификатор условий)
                         × (1 + Модификатор игрока)
                         × (1 + Модификатор мира)
                         × (1 + Случайный фактор)
```

**Где:**
- **Базовая вероятность:** 5–30% (зависит от типа семени).
- **Модификатор условий:** насколько условия выполнены (0–1).
- **Модификатор игрока:** действия игрока (предотвращение — минус, ускорение — плюс).
- **Модификатор мира:** события мира (война, климат, память).
- **Случайный фактор:** ±10% (для непредсказуемости).

### 11.3.4. Пример: бунт в Кампании

> **Базовая вероятность:** 15%.
> **Условия:** недовольство 70 (>60 → модификатор +0.2).
> **Игрок:** отправил деньги (−0.3).
> **Мир:** память о бунтах (+0.1).
> **Случайный фактор:** +0.05.
>
> Итог: 15% × (1 + 0.2) × (1 − 0.3) × (1 + 0.1) × (1 + 0.05) = **14.5%**.

### 11.3.5. Срок жизни

| Тип семени | Срок жизни |
|---|---|
| Бунт | 10 ходов |
| Мятеж | 15 ходов |
| Заговор | 20 ходов |
| Скандал | 5 ходов |
| Болезнь | 8 ходов |
| Война | 25 ходов |

> **Принцип:** семя не живёт вечно. Если условия не выполнены за срок жизни — оно рассасывается.

### 11.3.6. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Лимит семян превышен** | Новые семена не создаются (или заменяют старые) |
| **Семя сработало** | Уничтожается (или порождает новое семя — «последствия») |
| **Семя рассосалось** | Игрок может узнать постфактум |
| **Игрок обнаружил семя** | Может предотвратить или ускорить |

## 11.6. Проверка: формула вероятности, модификаторы, срок жизни

### 11.6.1. Философия: «Проверка — это не гарантия, а вероятность»

> **Принцип:** проверка **не даёт** гарантированного результата. Семя **может** сработать, а **может** рассосаться. Это создаёт **риск** и **непредсказуемость**.

### 11.6.2. Формула вероятности

```
Вероятность срабатывания = Базовая вероятность
                         × (1 + Модификатор условий)
                         × (1 + Модификатор игрока)
                         × (1 + Модификатор мира)
                         × (1 + Случайный фактор)
```

**Где:**
- **Базовая вероятность:** 5–30% (зависит от типа семени).
- **Модификатор условий:** насколько условия выполнены (0–1).
- **Модификатор игрока:** действия игрока (предотвращение — минус, ускорение — плюс).
- **Модификатор мира:** события мира (война, климат, память).
- **Случайный фактор:** ±10% (для непредсказуемости).

### 11.6.3. Модификаторы условий

| Условие | Модификатор |
|---|---|
| **Условия не выполнены** | 0 (семя холодное) |
| **Условия близки к выполнению** | +0.1–0.2 (семя тёплое) |
| **Условия выполнены** | +0.3–0.5 (семя горячее) |
| **Условия значительно превышены** | +0.5–1.0 (семя очень горячее) |

### 11.6.4. Модификаторы игрока

| Действие игрока | Модификатор |
|---|---|
| **Отправил деньги** | -0.3 (предотвращение) |
| **Усилил гарнизон** | -0.2 (предотвращение) |
| **Унизил врага** | +0.2 (ускорение) |
| **Не ответил на письмо** | +0.1 (ускорение) |
| **Забыл о обещании** | +0.1 (ускорение) |

### 11.6.5. Модификаторы мира

| Событие мира | Модификатор |
|---|---|

### 11.6.6. Срок жизни

| Тип семени | Срок жизни |

| Мятеж | 15 ходов |
| Заговор | 20 ходов |
| Скандал | 5 ходов |
| Болезнь | 8 ходов |

> **Принцип:** семя не живёт вечно. Если условия не выполнены за срок жизни — оно рассасывается.

### 11.6.7. Пример: бунт в Кампании

> **Базовая вероятность:** 15%.
> **Условия:** недовольство 70 (>60 → модификатор +0.2).
> **Игрок:** отправил деньги (−0.3).
> **Мир:** память о бунтах (+0.1).
> **Случайный фактор:** +0.05.
>
> Итог: 15% × (1 + 0.2) × (1 − 0.3) × (1 + 0.1) × (1 + 0.05) = **14.5%**.

## 11.7. Обнаружение: симптомы, расследование

### 11.7.1. Философия: «Семя невидимо, но его симптомы — нет»

> **Принцип:** игрок **не видит** семя. Но он **видит** симптомы: слухи, знамения, странности. Он **может** **расследовать** их, чтобы **раскрыть** семя.

### 11.7.2. Симптомы (что игрок видит)

| Стадия | Симптомы | Канал |
|---|---|---|
| **Холодное** | Ничего (только случайные слухи) | — |
| **Тёплое** | Слухи, странности, намёки | Слухи, письма, диалоги |
| **Горячее** | Явные предупреждения, доносы | Письма, гонцы, диалоги |

### 11.7.3. Примеры симптомов

| Семя | Симптом |
|---|---|
| Бунт | «В Кампании неспокойно» (слух), «Плебс ропщет» (письмо) |
| Мятеж губернатора | «Губернатор странно себя ведёт» (слух), «Он не отвечает на письма» (донос) |
| Заговор | «Говорят, готовится убийство» (слух), «Тебя спрашивали о планах» (диалог) |
| Скандал | «Говорят, ты изменяешь жене» (слух), «Твоя жена грустна» (диалог) |
| Болезнь | «Ты выглядишь бледным» (диалог), «Ты чувствуешь слабость» (текст) |

### 11.7.4. Расследование (действия игрока)

| Действие | Стоимость | Эффект |
|---|---|---|
| **Послать слугу** | 1 ОД + 100–500 | Узнать правду (шанс 60%) |
| **Спросить друга** | 1 ОД | Узнать правду (шанс 50%) |
| **Использовать Astutia** | 1 ОД | Проверка Astutia (шанс = Astutia/10) |
| **Нанять информатора** | 1 ОД + 500–2000 | Узнать правду (шанс 80%) |

### 11.7.5. Результат расследования

| Результат | Эффект |
|---|---|
| **Успех** | Игрок узнаёт о семени (тип, цель, стадия) |
| **Провал** | Ничего не узнаёт (или получает ложную информацию) |
| **Критический успех** | +5 Gratia, +2 Fama (успешное расследование) |
| **Критический провал** | -5 Gratia (слухи о провале) |

### 11.7.6. Ложные симптомы

> **Важно:** симптомы **могут** быть **ложными**. Слух «в Кампании неспокойно» может быть правдой (семя бунта) или ложью (враг распустил слух). Игрок **должен** **проверять**.

### 11.7.7. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Игрок игнорирует симптомы** | Семя срабатывает (без предупреждения) |
| **Игрок расследует** | Может раскрыть семя (и предотвратить) |
| **Игрок не расследует** | Семя остаётся скрытым |
| **Ложные симптомы** | Игрок тратит ресурсы зря |

## 11.8. Предотвращение и ускорение: способы влияния

### 11.8.1. Философия: «Игрок может играть с семенами»

> **Принцип:** игрок **может** **предотвратить** семя (если не хочет события) или **ускорить** его (если хочет). Это создаёт **стратегию** и **контроль** (частичный).

### 11.8.2. Предотвращение (как устранить семя)

| Семя | Способ предотвращения | Эффект |
|---|---|---|
| **Бунт** | Отправить деньги, гарнизон, визит | Условия не выполняются → семя рассасывается |
| **Мятеж губернатора** | Сместить, подкупить, повысить лояльность | Лояльность растёт → семя рассасывается |
| **Заговор** | Раскрыть, устранить врага, подкупить | Враждебность падает → семя рассасывается |
| **Скандал** | Опровергнуть, подкупить свидетелей | Fama растёт → семя рассасывается |
| **Болезнь** | Отдохнуть, позвать врача, помолиться | Здоровье растёт → семя рассасывается |

### 11.8.3. Ускорение (как ускорить семя)

| Семя | Способ ускорения | Эффект |
|---|---|---|
| **Бунт** | Повысить налог, убрать гарнизон | Условия выполняются быстрее |
| **Мятеж губернатора** | Унизить, не выплатить | Лояльность падает быстрее |
| **Заговор** | Оскорбить врага, угрожать | Враждебность растёт быстрее |
| **Война** | Ультиматум, вторжение | Отношения падают быстрее |

### 11.8.4. Как игрок узнаёт о способах

> **Принцип:** игрок **не видит** список способов. Он **должен** **догадаться** (или узнать через расследование). Например, если он знает, что губернатор нелоялен, он **может** **предположить**, что его нужно сместить.

### 11.8.5. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Игрок предотвратил семя** | Семя рассасывается (но может вернуться, если условия снова выполнятся) |
| **Игрок ускорил семя** | Семя срабатывает быстрее (но риск больше) |
| **Игрок не знает о семени** | Не может ни предотвратить, ни ускорить |
| **Игрок знает, но не действует** | Семя развивается само |

## 11.9. Взаимодействие семян: усиление, ослабление, порождение новых

### 11.9.1. Философия: «Семена не изолированы»

> **Принцип:** семена **не** существуют **в вакууме**. Они **взаимодействуют** друг с другом: **усиливают**, **ослабляют** или **порождают** новые. Это создаёт **сложность** и **непредсказуемость**.

### 11.9.2. Усиление (комбинации)

| Комбинация | Эффект |
|---|---|
| **Бунт + Мятеж губернатора** | Гражданская война (крупное событие) |
| **Заговор + Скандал** | Изгнание / смерть (шанс выше) |
| **Голод + Эпидемия** | Катастрофа (падение населения вдвое) |
| **Война + Пиратство** | Экономический кризис (доход падает на 50%) |
| **Болезнь + Стресс** | Смерть (шанс выше) |

### 11.9.3. Ослабление (комбинации)

| Комбинация | Эффект |
|---|---|
| **Победа + Заговор** | Враги боятся, заговор ослабевает (шанс -20%) |
| **Богатство + Скандал** | Деньги заглушают скандал (Fama не падает) |
| **Высокая Pietas + Болезнь** | Боги помогают, болезнь ослабевает (шанс -15%) |
| **Мир + Бунт** | Мир успокаивает, бунт ослабевает (шанс -10%) |

### 11.9.4. Порождение новых семян

### 11.9.5. Пример: взаимодействие семян
