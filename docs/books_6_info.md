### 6.1.1. Философия: «Информация — это не дашборд»

> **Принцип:** игрок **не видит** мир «сверху». Он получает **сообщения** — письма, слухи, донесения. Каждое сообщение — это **решение**, которое нужно принять.

## 6.2. Структура сообщения

### 6.2.1. Поля сообщения

| Поле | Описание | Пример |
|---|---|---|
| **ID** | Уникальный идентификатор | `msg_001` |
| **Тип** | Категория (из 68 типов) | Просьба денег |
| **Отправитель** | Кто прислал | Губернатор Кампании |
| **Канал** | Как дошло | Письмо / Слух / Клиент / Раб / Друг / Жена / Форум |
| **Содержание** | Текст (заготовка или LLM) | «Урожай плох, нужны деньги» |
| **Срочность** | 1–4 | 3 (высокая) |
| **Достоверность** | 1–3 | 2 (средняя) |
| **Слои тайны** | Если это тайна | Уровень 1 (слух) |
| **Последствия** | Что будет при ответе/игнорировании | Бунт, благодарность |
| **Связь с событием** | Какое событие породило | Голод в Кампании |

### 6.2.2. Как сообщение попадает в очередь

```
Событие (мир, NPC, действие игрока)
    ↓
Триггер (что-то произошло)
    ↓
Канал (как информация доходит)
    ↓
Сообщение (сформировано)
    ↓
Очередь (6.4)
    ↓
Игрок (видит, решает)
```

### 6.2.3. Что видит игрок

> **Принцип:** игрок **не видит** полей «срочность» и «достоверность». Он видит:
- **Текст** (письмо, слух, диалог).
- **Отправителя** (если известен).
- **Контекст** (что произошло).

**Срочность** и **достоверность** — «под капотом». Игрок **должен сам** оценить, насколько срочно и правдиво.

## 6.3. Каналы доставки

### 6.3.1. Философия: «Информация — это социальный капитал»

> **Принцип:** в Риме информация **не покупалась** — она **обменивалась** (или **утаивалась**) в рамках социальных обязательств. Игрок **не нанимает** шпионов — он **использует** социальные связи.

### 6.3.2. Шесть каналов

| Канал | Источник | Скорость | Качество | Риск |
|---|---|---|---|---|
| **Фамилия (рабы)** | Рабы, вольноотпущенники, домочадцы | 1–3 хода | Среднее | Раб может быть подкуплен |
| **Клиентела** | Клиенты (плебеи, всадники, вольноотпущенники) | 2–5 ходов | Среднее | Может преувеличить |
| **Амициция** | Друзья (сенаторы, военные, жрецы) | 1–4 хода | Высокое | Может использовать |
| **Род** | Родственники (близкие, дальние, свойственники) | 2–6 ходов | Высокое | Может предать |
| **Женщины** | Жена, мать, сестра, любовница | 1–3 хода | Высокое | Может скрыть |
| **Публичная жизнь** | Форум, Сенат, бани, игры, храмы | 0–1 ход | Среднее | — |

### 6.3.3. Детали каналов

**Фамилия (рабы):**
- Рабы **слышат** разговоры хозяев, гостей, других рабов.
- Шанс узнать = (Число ваших рабов / 10) × (Число рабов цели / 10) × 0.1.
- Раб может быть **подкуплен** (10% в год).

**Клиентела:**
- Клиенты **приходят** утром (salutatio) — это **ритуал**.
- Каждый клиент приносит **1 слух** (с вероятностью 50%).
- Клиент может **уйти** к другому патрону (15% в год).

**Амициция:**
- Друзья **делятся** информацией **добровольно** (но ждут reciprocity).
- Друг делится, если: вы делились с ним раньше, информация касается вас обоих, он хочет предупредить.
- Друг может **предать** (5% в год).

**Род:**
- Родственники **связаны** кровью и **делятся** информацией (но не всегда).
- Вы можете **посетить** родственника (1 ОД) или **написать** письмо (1 ОД).
- Родственник может **использовать** информацию против вас (5% в год).

**Женщины:**
- Женщины **знали больше**, чем принято думать.
- Жена делится, если: Amor > 50, информация касается семьи, вы сами спросили.
- Жена может **скрыть** (20% в год, если Amor < 50).

**Публичная жизнь:**
- Вы **сами** ходите по городу и **наблюдаете**.
- Раз в ход (если в Риме) вы выбираете **1 место** (1 ОД).
- Проверка Astutia (A05) → успех → больше деталей.

### 6.3.4. Как каналы взаимодействуют

> **Принцип:** один канал может **подтвердить** или **опровергнуть** другой. Разные каналы могут дать **разные уровни** информации (слух vs фрагмент). Чем больше каналов — тем **больше информации**, но **больше шума**.

## 6.4. Очередь сообщений

### 6.4.1. Формирование очереди (каждый ход)

**Шаг 1. Определение пула возможных сообщений:**
```
Пул = Все сообщения, чьи триггеры сработали в этом ходу
```

**Триггеры:**
- **События мира** (F): катастрофы, действия держав, набеги народов.
- **Действия NPC** (A07, B02): просьбы, доносы, приглашения.
- **Действия игрока** (A03): последствия решений.
- **Случайные события** (G03): слухи, встречи.
- **Календарь** (B01, B05): выборы, праздники, налоги.

**Шаг 2. Фильтрация по локации и статусу:**

| Статус игрока | Доступные каналы |
|---|---|
| **Дома (Рим)** | Все, кроме военных донесений (если нет войск в Риме) |
| **В командировке** | Письма, экономика, армия, личное; Сенат — только через гонцов |
| **В путешествии** | Только личное; письма с опозданием |
| **На войне** | Армия, личное; письма только военные |

**Шаг 3. Приоритизация:**
```
Приоритет = (Срочность × 10) + (Важность × 5) + (Случайный фактор)
```

- **Срочность:** 1–4 (немедленно, высокая, средняя, низкая).
- **Важность:** 1–3 (критично для игры, важно, фоновое).

**Шаг 4. Ограничение очереди:**
> **Максимум 5 сообщений в очереди.** Если пул больше — выбираются с highest приоритетом. Остальные **теряются** (игрок о них не узнает, но последствия могут быть).

**Шаг 5. Отображение игроку:**
- Сообщения показываются в порядке приоритета (сначала срочные).
- Игрок может **прочитать** (0 ОД) или **ответить** (1 ОД).
- Неотвеченные сообщения **возвращаются** в следующем ходу с пометкой «напоминание».

### 6.4.2. Накопление «долгов»

| Ситуация | Последствие |
|---|---|
| Сообщение не прочитано 1 ход | Возвращается с пометкой |
| Не прочитано 2 хода | Разрешается автоматически (обычно негативно) |
| Не прочитано 3 хода | Серьёзное последствие (бунт, скандал, потеря влияния) |
| Очередь > 5 | Новые сообщения теряются (игрок не знает) |

### 6.4.3. Пример: ход 10, игрок дома

> **Триггеры:**
> - Просьба губернатора (срочность 3, важность 2).
> - Приглашение друга (срочность 1, важность 1).
> - Требование Сената (срочность 4, важность 3).
> - Слух о пиратах (срочность 2, важность 2).
>
> **Приоритеты:**
> - Сенат: 40 + 15 = 55.
> - Губернатор: 30 + 10 = 40.
> - Слух: 20 + 10 = 30.
> - Друг: 10 + 5 = 15.
>
> **Очередь:** Сенат, губернатор, слух, друг. Все 4 помещаются.
>
> **Если бы было 6 сообщений** — друг и слух могли бы потеряться.

|---|---|---|
| **4** | Немедленно | Катастрофа (бунт, поражение, смерть) |
| **3** | Высокая | Серьёзные проблемы (потеря денег, влияния) |
| **2** | Средняя | Умеренные проблемы (ухудшение отношений) |
| **1** | Низкая | Незначительные проблемы (упущенные возможности) |

**Формула срочности:**
```
Срочность = Базовая срочность типа сообщения 
            + Модификатор контекста 
            + Модификатор отправителя
```

**Модификаторы:**
- **Контекст:** война +1, кризис +1, мир -1.
- **Отправитель:** друг +1, враг -1, официальное лицо +1.

### 6.5.2. Достоверность (1–3)

| Уровень | Название | Как игрок узнаёт |
|---|---|---|
| **3** | Высокая | Известная репутация отправителя, проверенные факты |
| **2** | Средняя | Может быть преувеличена, нужны проверки |
| **1** | Низкая | Может быть ложью, нужны расследования |

**Формула достоверности:**
```
Достоверность = Базовая достоверность типа сообщения 
                + Модификатор отправителя 
                + Модификатор контекста 
                - Модификатор заинтересованности
```

**Модификаторы:**
- **Отправитель:** честный +1, лживый -1, неизвестный 0.
- **Контекст:** мир +1, война -1, кризис -1.
- **Заинтересованность:** если отправитель выигрывает от лжи -1.

### 6.5.3. Пример

> **Письмо от губернатора Кампании:**
> - Тип: просьба денег (базовая достоверность 2).
> - Отправитель: известен как честный (+1).
> - Контекст: мир (+1).
> - Заинтересованность: он просит денег, может преувеличивать (-1).
> - **Достоверность:** 2 + 1 + 1 - 1 = **3** (высокая).

> **Слух от купца:**
> - Тип: слух (базовая достоверность 1).
> - Отправитель: неизвестен (0).
> - Контекст: война (-1).
> - Заинтересованность: купец может преувеличивать (-1).
> - **Достоверность:** 1 + 0 - 1 - 1 = **-1 → 1** (низкая).

### 6.5.4. Как игрок узнаёт о достоверности

- **Прямо:** никогда (нет значка «правда/ложь»).
- **Косвенно:** через репутацию отправителя (если известна), через слухи, через проверки (G04).
- **Постфактум:** если сообщение оказалось ложным, игрок может запомнить отправителя.

### 6.5.5. Крайние случаи

| Ситуация | Что происходит |
|---|---|
| **Срочность 4** | Сообщение прерывает ход, требует немедленного решения |
| **Достоверность 1** | Сообщение может быть полностью ложным |
| **Отправитель-враг** | Достоверность -1 (он может лгать) |
| **Отправитель-друг** | Достоверность +1 (но он может ошибаться) |

## 6.6. Слухи

### 6.6.1. Философия: «Слух — это оружие и щит»

> **Принцип:** слух — это **непроверенная информация**, которая может быть правдой, ложью или преувеличением. Игрок **не может** доверять слухам полностью, но **не может** их игнорировать. Слухи — это **инструмент тумана войны**.

### 6.6.2. Источники слухов (7)

| Источник | Где | Частота | Базовое доверие |
|---|---|---|---|
| **Форум** | Рим | Каждый ход (если дома) | 30% |
| **Таверны** | Путешествие | 50% | 20% |
| **Бани** | Рим | 30% | 25% |
| **Купцы** | Торговые пути | 40% | 40% |
| **Слуги** | Дом | 20% | 50% |
| **Друзья** | Диалоги | 30% | 60% |
| **Враги** | Диалоги | 20% | 10% |

### 6.6.3. Формула правдивости слуха

```
Вероятность правды = Базовое доверие источника 
                     + (Astutia игрока / 10) × 5% 
                     - (Влияние врага / 10) × 10% 
                     + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..95%.

### 6.6.4. Пример: слух от купца о пиратах

> - Базовое доверие 40%.
> - Astutia 60 → +30%.
> - Влияние врага 20 → -20%.
> - Случайный +5%.
> - **Вероятность правды: 55%.**

### 6.6.5. Проверка слухов

| Действие | Стоимость | Эффект |
|---|---|---|
| **Послать слугу** | 1 ОД + 100–500 | Узнать правду (шанс 60%) |
| **Спросить друга** | 1 ОД | Узнать правду (шанс 50%) |
| **Использовать Astutia** | 1 ОД | Проверка Astutia (шанс = Astutia/10) |
| **Нанять информатора** | 1 ОД + 500–2000 | Узнать правду (шанс 80%) |

### 6.6.6. Последствия слухов

| Слух | Если правда | Если ложь |
|---|---|---|
| **О пиратах** | Подготовиться (флот) | Потратить деньги зря |
| **О заговоре** | Проверить, предотвратить | Оскорбить невиновного |
| **Об измене жены** | Развод, скандал | Оскорбить жену, -Amor |
| **О войне** | Подготовиться | Мобилизация зря |

### 6.6.7. Пример: слух «В Кампании неспокойно» (правда 60%)

> - **Игрок верит:** отправляет деньги (1000) → +5 довольство, +5 отношения.
> - **Если правда:** бунт предотвращён.
> - **Если ложь:** деньги потрачены зря, но отношения не ухудшились.
>
> **Игрок проверяет:** посылает слугу (1 ОД + 300) → узнаёт правду (60%).
> - **Если правда:** подтверждено, действует.
> - **Если ложь:** не действует, экономит деньги.

### 6.6.8. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Слух от врага** | Вероятность правды 10% (он лжёт) |
| **Слух от друга** | Вероятность правды 60% (но он может ошибаться) |
| **Слух о смерти** | Может быть правдой или ложью (проверка важна) |
| **Слух о заговоре** | Если проигнорировать, заговор может сработать (G05) |

## 6.7. Скрытые преступления

### 6.7.1. Философия: «Тайна — это не «флаг», а процесс»

> **Принцип:** в реальном Риме **невозможно было сохранить тайну навсегда**. Рабы слышали, вольноотпущенники болтали, враги подслушивали, а тела находили. Но **узнать правду** было трудно, **доказать** — ещё труднее, а **использовать** — опасно.

### 6.7.2. Уровни знания (5)

| Уровень | Что игрок знает | Что может сделать |
|---|---|---|
| **0. Ничего** | Ничего не подозревает | — |
| **1. Смутный слух** | «Говорят, что-то случилось в роду Корнелиев» | Игнорировать, проверить |
| **2. Фрагмент** | «Говорят, Корнелии убили Сципиона» | Проверить, использовать |
| **3. Подозрение** | «У меня есть основания думать, что это правда» | Искать доказательства |
| **4. Уверенность** | «Я знаю, кто это сделал» | Действовать (суд, шантаж, союз) |
| **5. Доказательство** | «У меня есть свидетели/документы» | Публично обвинить (B06) |

### 6.7.3. Слои тайны (4)

| Слой | Что скрыто | Сложность раскрытия |
|---|---|---|
| **1. Событие** | Что произошло | 1 |
| **2. Личности** | Кто сделал | 2 |
| **3. Мотив** | Почему | 3 |
| **4. Доказательства** | Чем подтвердить | 4 |

> **Принцип:** игрок может знать слой 1 (что-то случилось), но не знать слои 2–4. Это создаёт **напряжение**: «Я знаю, что это сделали Корнелии, но не могу доказать».

### 6.7.4. Каналы утечки тайны

| Канал | Вероятность | Задержка | Качество |
|---|---|---|---|
| **Рабы** | 5% | 2–5 ходов | Среднее |
| **Клиенты** | 10% | 3–6 ходов | Среднее |
| **Друзья** | 8% | 2–4 хода | Высокое |
| **Род** | 3% | 4–8 ходов | Высокое |
| **Женщины** | 6% | 2–4 хода | Высокое |
| **Публичная жизнь** | 4% | 1–3 хода | Среднее |

### 6.7.5. Как игрок расследует

| Действие | Стоимость | Эффект |
|---|---|---|
| **Послать слугу** | 1 ОД + 100–500 | Узнать правду (шанс 50%) |
| **Спросить друга** | 1 ОД | Узнать правду (шанс 40%) |
| **Использовать Astutia** | 1 ОД | Проверка Astutia (шанс = Astutia/10) |
| **Нанять информатора** | 1 ОД + 500–2000 | Узнать правду (шанс 70%) |

### 6.7.6. Пример: убийство Марка Сципиона

> **Предыстория:** Корнелии убили Марка Сципиона. Тело спрятали. Слуги запуганы. Клавдии (враги Корнелиев) что-то подозревают.
>
> **Ход 1:** семя `secret_murder_cornelii` создано.
> **Ход 3:** раб на рынке слышит слух (5%). Симптом: «В доме Корнелиев что-то случилось».
> **Ход 4:** клиент приносит слух (10%). Симптом: «Марк Сципион исчез».
> **Ход 5:** друг намекает (8%). Симптом: «Поговори с вольноотпущенником Корнелиев».
> **Ход 6:** игрок подкупает вольноотпущенника (1000). Уровень 4 (уверенность).
> **Ход 7:** игрок решает, что делать (суд, шантаж, союз).

### 6.7.7. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Игрок знает, но не может доказать** | Может шантажировать (риск), но не может обвинить в суде |
| **Игрок обвиняет без доказательств** | -Gratia, -Fama, риск ответного иска |
| **Игрок молчит** | Тайна остаётся, но может выйти позже |
| **Тайна раскрыта** | Цель теряет Fama, Gratia, может быть изгнана |

## 6.8. Расследование

### 6.8.1. Философия: «Расследование — это не гарантия, а риск»

> **Принцип:** расследование **не даёт** гарантированного результата. Игрок **тратит** ОД и деньги, но **может** провалиться (или получить ложную информацию). Это создаёт **риск** и **непредсказуемость**.

### 6.8.2. Типы расследований

| Тип | Что проверяет | Стоимость | Шанс успеха |
|---|---|---|---|
| **Проверка слуха** | Правда или ложь | 1 ОД + 100–500 | 50–80% |
| **Раскрытие семени** | Существует ли скрытая угроза | 1 ОД + 200–1000 | 40–70% |
| **Проверка отправителя** | Лжёт ли NPC | 1 ОД + 100–300 | 60–90% |
| **Поиск компромата** | Есть ли компромат на цель | 1 ОД + 500–2000 | 30–60% |

### 6.8.3. Формула успеха

```
Шанс успеха = База (50%) 
              + (Astutia / 10) × 5% 
              + (Деньги / 500) × 5% 
              - (Сложность × 10%) 
              + Случайный фактор (-10%..+10%)
```

**Сложность:**

| Сложность | Что это | Пример |
|---|---|---|
| **1** | Простой слух | Правда/ложь |
| **2** | Семя | Скрытая угроза |
| **3** | Заговор | Высокая сложность |
| **4** | Доказательства | Почти невозможно |

### 6.8.4. Пример: расследование семени бунта в Кампании

> - Astutia 60 → +30%.
> - Деньги 500 → +5%.
> - Сложность 2 → -20%.
> - Случайный +3%.
> - **Шанс: 50 + 30 + 5 - 20 + 3 = 68%.**

### 6.8.5. Результаты

| Результат | Эффект |
|---|---|
| **Успех** | Игрок узнаёт правду (семя, слух, ложь). |
| **Провал** | Игрок не узнаёт (или получает ложную информацию). |
| **Критический успех** | +5 Gratia, +2 Fama (успешное расследование). |
| **Критический провал** | -5 Gratia (слухи о провале). |

### 6.8.6. Как игрок узнаёт

| Канал | Что даёт |
|---|---|
| **Диалог с информатором** | «Я узнал, что...» |
| **Письмо** | «Мой человек донёс...» |
| **Слух** | «Говорят, ты кого-то подослал» |

### 6.8.7. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Astutia 100** | Шанс +50% |
| **Деньги 2000** | Шанс +20% |
| **Сложность 3** | Шанс -30% |
| **Провал** | Игрок может потратить ещё деньги и ОД (повторная попытка) |

## 6.9. LLM-диалоги с NPC

### 6.9.1. Философия: «LLM — это не движок правил, а инструмент»

> **Принцип:** LLM **не управляет** игрой. Она **генерирует текст**, но **результат** определяется **игрой** (структурированный вывод). Это защищает баланс от «галлюцинаций» модели.

### 6.9.2. Когда происходят диалоги

| Ситуация | Когда |
|---|---|
| **NPC приходит лично** | Друг, враг, сенатор, купец |
| **Игрок сам идёт к NPC** | Тратит ОД |
| **Случайная встреча** | На Форуме, в банях, на пирушке |

### 6.9.3. Что даёт диалог

| Что | Как работает |
|---|---|
| **Информация** | Слухи, новости, предупреждения (G03) |
| **Убеждение** | Изменить отношения (B03) |
| **Подкуп** | Деньги за услугу (B04) |
| **Угроза** | Страх за услугу (I04) |
| **Раскрытие лжи** | Проверка Astutia (G04) |

### 6.9.4. Системный промпт

```
Ты — [имя NPC], [должность/роль]. Твой характер: [черты]. 
Твоё отношение к игроку: [слово]. Ты помнишь: [3-5 событий].
Текущий контекст: [событие].
Ответь на сообщение игрока. Верни JSON:
{
  "text": "твой ответ",
  "attitude_change": "улучшил/ухудшил/нейтрально",
  "information": "раскрыл/скрыл/нет",
  "promise": "да/нет"
}
```

### 6.9.5. Обработка результата

| Поле | Категория | Числовой эффект |
|---|---|---|
| **attitude_change** | улучшил | +10 отношения |
| | нейтрально | 0 |
| | ухудшил | -10 отношения |
| **information** | раскрыл | игрок получает слух (G03) |
| | скрыл | ничего |
| **promise** | да | обязательство NPC (B03) |
| | нет | — |

### 6.9.6. Пример: игрок пишет Крассу

> **Промпт:** «Ты — Красс, оптимат, гордый, недоверчивый. Отношение: Недоволен. Помнишь, что игрок унизил тебя в Сенате».
>
> **Игрок редактирует:** «Красс, друг мой, поддержки...»
>
> **LLM возвращает:**
> ```json
> {
>   "text": "Я подумаю, но не забыл твоей выходки.",
>   "attitude_change": "ухудшил",
>   "information": "скрыл",
>   "promise": "нет"
> }
> ```
>
> **Игра применяет:** -10 отношения, слух не раскрыт, обещания нет.

### 6.9.7. Ограничения

| Ограничение | Что это значит |
|---|---|
| **LLM не может** менять состояние мира напрямую | Только через структурированный результат |
| **LLM не может** генерировать числа | Только категории |
| **LLM не может** противоречить правилам игры | Не может «убить» NPC без семени |

### 6.9.8. Крайние случаи

| Ситуация | Что происходит |
|---|---|
| **LLM галлюцинирует** | Игра игнорирует текст, использует только структурированный результат |
| **LLM не отвечает** | Таймаут (2–3 сек), игра использует заготовку |
| **Игрок вводит оскорбления** | LLM возвращает «ухудшил», игра применяет -10 отношения |
| **Промпт слишком длинный** | Обрезается до 3–5 ключевых событий |
