## 13.1. Фундамент (A01–A07)

### A01. Модель модификаторов ОД

```
Итоговое ОД = Базовое ОД (3) + Сумма модификаторов
```

**Модификаторы (суммируются):**

| Источник | Модификатор |
|---|---|
| **Статус «Дома»** | +1 |
| **Статус «В командировке»** | 0 |
| **Статус «В путешествии»** | -1 |
| **Статус «На войне»** | 0 |
| **Здоровье: Крепок / Бодр** | 0 |
| **Здоровье: Устал / Хвораю** | -1 |
| **Здоровье: Болен / Тяжко болен** | -2 |
| **Здоровье: При смерти** | -3 |
| **Стресс: Безмятежен / Спокоен** | 0 |
| **Стресс: Озабочен** | 0 (-1 к концентрации) |
| **Стресс: Утомлён / Измотан** | -1 |
| **Стресс: На грани** | -2 |
| **Стресс: Сломлен** | -3 |
| **Черта «Энергичный»** | +1 |
| **Черта «Быстрота мысли»** | +1 |
| **Черта «Лень»** | -1 |
| **Черта «Меланхолия»** | -1 |
| **Верный помощник** | +1 |
| **Временный эффект** | -1 |

**Ограничение:** минимум 1 ОД.

### A03. Модель изменения шкал

```
Новое значение = Текущее значение + Δ
Δ = Базовое изменение × Модификатор черт × Модификатор обстоятельств × Случайный фактор
```

**Модификаторы черт:**

| Черта | Эффект на Δ |
|---|---|
| «Жестокий» | +50% к негативным изменениям Fama |
| «Благочестивый» | +50% к положительным изменениям Pietas Deorum |
| «Меланхолик» | +50% к положительным изменениям Stress |
| «Энергичный» | -20% к положительным изменениям Stress |
| «Хитрый» | -30% к негативным изменениям Fama |

**Случайный фактор:** 1 + (случайное число от -0.1 до +0.1).

### A04. Модель старения и смерти

**Старение:** -1 Health в год после 40, -2 после 60, -3 после 70.

**Проверка смерти от старости (раз в год):**
```
Вероятность = (Возраст - 40) × 0.5% + (100 - Здоровье) × 0.1%
```

**Проверка болезни (раз в ход, если здоровье < 30):**
```
Вероятность = (30 - Здоровье) × 1% + (Возраст - 50) × 0.5%
```

**Проверка смерти от тоски (раз в ход, если стресс > 85):**
```
Вероятность = (Stress - 85) × 2%
```

**Проверка смерти от порока (раз в ход, если черта и здоровье < 40):**
```
Вероятность = (40 - Здоровье) × 1% + (Stress - 60) × 0.5%
```

**Проверка смерти от ран (после битвы, если проиграл):**
```
Вероятность = 5% + (Потери / 1000) × 1%
```

**Проверка смерти от убийцы (при срабатывании семени):**
```
Вероятность = 30% - (Astutia × 3%) - (Охрана × 5%)
```

### A05. Общая модель проверок

```
Шанс успеха = 50% 
            + clamp((Навык игрока - Навык цели) × 2%, -30%, +30%)
            + Сумма модификаторов
            + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..95%.

**Модификаторы:**

| Модификатор | Эффект |
|---|---|
| Fama > 70 | +10% |
| Fama < 30 | -10% |
| Стресс > 70 | -10% |
| Стресс < 20 | +5% |
| Pietas Deorum > 70 | +5% |
| Pietas Deorum < 30 | -5% |
| Подкуп (за 1000) | +5% |
| Угроза | +10% (но +враждебность) |
| Поддержка фракции | +10% |
| Сопротивление фракции | -10% |
| Похмелье | -15% |
| Помощник | +5% |

## 13.2. Провинции (E01–E06)

### E01. Модель состояния провинции

**Формула изменения за ход (2 недели):**

```
Δ Население = (Рост от плодородия - Потери от голода - Потери от войны - Потери от болезней) × 0.01
Δ Довольство = (Налоговая нагрузка + Война + Память + Губернатор) × 0.5
Δ Инфраструктура = (Вложения - Деградация) × 0.01
Δ Плодородие = (Климат + Война + Истощение) × 0.01
```

**Рост населения:**
```
Рост = (Плодородие / 100) × (Вода / 100) × 0.5
```

**Потери от голода:**
```
Если Продовольствие < Население:
    Потери = (Население - Продовольствие) × 0.1
```

**Потери от войны:**
```
Если Угроза > 50:
    Потери = (Угроза - 50) × 0.05
```

**Потери от болезней:**
```
Если Вода < 30:
    Потери = (30 - Вода) × 0.02
```

**Налоговая нагрузка на довольство:**
```
Δ Довольство от налогов = -(Налог - 30) × 0.05
```

**Деградация инфраструктуры (без вложений):**
```
Дороги: 0.5, Порты: 0.3, Админ: 0.2, Укрепления: 0.1, Вода: 0.2
```

### E02. Модель ресурсов и специализации

**Добыча:**
```
Добыча = Уровень добычи × (1 - Истощение) × Модификатор инфраструктуры
```

**Истощение (за год):**
```
Δ Истощение = 0.01 (железо), 0.02 (медь), 0.05 (серебро), 0.1 (золото)
```

**Смена специализации (вероятность за год):**
```
Вероятность = (Условие × 0.1) + (Время × 0.01)
```

**Ограничение:** не раньше 5 лет (120 ходов).

### E03. Модель довольства и бунта

**Формула довольства:**
```
Довольство = База (50)
           + (Губернатор × 5)
           + (Память о хорошем × 3)
           - (Налог - 30) × 0.5
           - (Память о бунтах × 5)
           - (Влияние врага × 0.3)
           - (Голод × 10)
           + (Праздники × 2)
```

**Вероятность бунта (каждый ход):**
```
Вероятность = (100 - Довольство) / 100 
            × (1 - Гарнизон / 100) 
            × (1 - Лояльность губернатора / 100)
            × (1 + Память о бунтах × 0.1)
            × (1 + Влияние врага × 0.05)
```

**Ограничение:** 1%..60%.

**Сила бунта:**
```
Сила = (100 - Довольство) × 0.5 + (Население / 10) + (Влияние врага × 5)
```

**Шанс подавления:**
```
Шанс = (Гарнизон / (Сила бунта × 2)) × 100 + (Военный опыт губернатора × 5)
```

### E04. Модель этно-религиозного состава

**Общее довольство:**
```
Общее довольство = Σ (share × satisfaction) / Σ share
```

**Риск конфликта:**
```
Риск = (1 - Доминирующая доля) × (1 - Средняя удовлетворённость / 100) × 100
```

**Влияние на бунты:** если крупная недовольная группа (share > 0.3, satisfaction < 30) → риск бунта × 2.

### E05. Модель губернатора

**Эффективность сбора налогов:**
```
Модификатор налогов = 0.5 + (Компетентность / 10)
```

**Риск воровства:**
```
Шанс воровства = (5 - Честность) × 0.05
```

**Риск мятежа:**
```
Шанс мятежа = (Амбиции × 0.05) × (1 - Лояльность / 5)
```

**Подавление бунта:**
```
Бонус = Военный опыт × 5%
```

**Коррупция:**
```
Украдено = Доход × (5 - Честность) × 0.02
```

### E06. Модель перемещения

**Стоимость ОД:**
```
Стоимость = 1 (база) + Модификатор расстояния
```

**Модификаторы расстояния:**

| Расстояние | Модификатор |
|---|---|
| Близкое | 0 |
| Среднее | 1 |
| Далёкое | 2 |
| Очень далёкое | 3 |

**Влияние дорог:**
```
Эффективное расстояние = Базовое расстояние / (1 + Дороги / 100)
```

**Риски в пути:**

| Риск | Вероятность | Эффект |
|---|---|---|
| Шторм | 10–20% | Задержка (1 ход), потеря груза |
| Пираты | 5–15% | Потеря денег, плен |
| Бандиты | 5–10% | Потеря денег |
| Болезнь | 5% | -10 здоровье |

## 13.3. Экономика (C01–C07)

### C01. Модель налогового дохода провинции

**Грязный доход:**
```
Грязный доход = Население × (Довольство / 100) × (Админ / 100) 
                × (0.5 + Налог / 100) 
                × Модификатор губернатора 
                × Модификатор ресурсов 
                × Модификатор состояния
                × Базовый коэффициент (100)
```

**Чистый доход:**
```
Чистый доход = Грязный доход × (1 - Коррупция губернатора)
```

**Коррупция губернатора:**
```
Коррупция = (5 - Честность) × 0.04
```

### C02. Модель личных доходов сенатора

**Формула:**
```
Личный доход = Σ (Источники) 
               × (1 - Воровство слуг) 
               × (1 - Инфляция / 2)
```

**Источники:**

| Источник | Формула |
|---|---|
| Поместья | Площадь (га) × Плодородие / 10 |
| Рабы | Число рабов × 5 |
| Мастерские | Вложение × 0.05 |
| Торговля | Инвестиции × 0.08 |
| Должность | Квестор 500, эдил 700, претор 1000, консул 2000, цензор 1500, проконсул 2500 |
| Подарки / взятки | Зависят от действий |
| Проценты по займам | Сумма × 0.1 |

### C03. Модель коррупции и воровства

**Коррупция губернатора:**
```
Коррупция = (5 - Честность) × 0.04
```

**Воровство слуг (шанс за ход):**
```
Шанс = (5 - Честность слуги) × 0.03 × (1 - Внимание игрока / 100)
```

**Украдено за ход:**
```
Украдено = Богатство × Шанс × 0.1
```

**Раскрытие:**
```
Шанс раскрытия = (5 - Честность) × 0.02 × (Внимание игрока / 100)
```

**Коррупция квестора:**
```
Шанс воровства = (5 - Честность квестора) × 0.02
Украдено = Оборот Казны × Шанс
```

### C04. Модель поместья и инвестиций

**Доход:**
```
Доход = Вложение × Базовая ставка × (1 - Риск) × (1 + Компетентность управляющего / 10)
```

**Базовые ставки:**

| Инвестиция | Базовая ставка |
|---|---|
| Поместье | 0.05 |
| Рабы | 0.10 |
| Мастерская | 0.08 |
| Торговый корабль | 0.10 |
| Рудник | 0.15 |

### C05. Модель цен и инфляции

**Инфляция (годовая):**
```
Инфляция (%) = (Средний налог - 30) × 0.5 
             + (Дефицит Казны × 5) 
             + (Война × 3)
```

**Влияние инфляции:**

| Инфляция | Цены | Довольство | Доход |
|---|---|---|---|
| 0–5% | +0% | 0 | 0 |
| 5–15% | +10% | -2 | -5% |
| 15–30% | +25% | -5 | -10% |
| 30–50% | +50% | -10 | -20% |
| 50%+ | +100% | -15, риск бунта | -30% |

**Реальная стоимость действий:**
```
Реальная стоимость = Базовая стоимость × (1 + Инфляция / 100)
```

### C06. Модель займов и долгов

**Максимальный займ:**
```
Максимальный займ = Личный доход (за квартал) × 5 × (Fama / 100)
```

**Процент:**
```
Процент (годовой) = 10% + (Инфляция × 0.5) + (Риск невыплаты × 10)
```

**Риск невыплаты:** 0 (есть поместья), 1 (только должность), 2 (нет ничего).

**Последствия невыплаты:**

| Просрочка | Эффект |
|---|---|
| 1 квартал | -5 Fama, +5% к проценту |
| 2 квартала | -10 Fama, риск суда |
| 3 квартала | Долговая кабала: потеря активов, -20 Fama |
| 4 квартала | Потеря должности, изгнание |

### C07. Модель торговли

**Доход от одного пути:**
```
Доход = Объём × Цена × Безопасность × Инфраструктура
```

**Безопасность:**
```
Безопасность = 1 - (Пираты / 100) - (Война / 100), минимум 0.1
```

**Инфраструктура:**
```
Инфраструктура = (Дороги + Порты) / 200, диапазон 0.1–1.0
```

**Уровень пиратства:**
```
Уровень = (1 - Флот / 100) × (1 - Война / 100) × 0.5
```

| **C04. Инвестиции** | вложение × ставка × (1 - риск) | Низкая |
| **C05. Инфляция** | (налог - 30) × 0.5 + дефицит + война | Низкая |
| **C06. Займы** | доход × 5 × (Fama / 100) | Средняя |
| **C07. Торговля** | объём × цена × безопасность × инфраструктура | Средняя |

## 13.4. Политика (B01–B08)

### B01. Модель голосования в Сенате

**Формула:**

```
Голоса ЗА = (Gratia / 10) + (Fama / 20) + (Поддержка фракций / 5) 
            + (Подкуп / 500) + (Союзники × 2) 
            + Случайный фактор (-3..+3)

Голоса ПРОТИВ = (Сопротивление фракций / 5) + (Важность закона × 2)
                + (Влияние врагов / 10) + Случайный фактор (-3..+3)
```

**Итог:** если `Голоса ЗА > Голоса ПРОТИВ` — закон принят.

**Модификаторы:**

| Модификатор | Эффект |
|---|---|
| Похмелье | -15% к голосам ЗА |
| Стресс «На грани» | -10% к голосам ЗА |
| Стресс «Безмятежен» | +5% к голосам ЗА |
| Fama «Безупречен» | +10% к голосам ЗА |
| Fama «Опозорен» | -15% к голосам ЗА |
| Должность (консул/трибун) | +10% к голосам ЗА |
| Враг в Сенате | +5 к голосам ПРОТИВ |

### B02. Модель фракций

**Влияние фракции:**

```
Влияние = (Сумма Gratia членов) / 10 + (Число сенаторов) × 2
```

**Отношения фракции с игроком:**

| Отношение | Поддержка | Сопротивление |
|---|---|---|
| Обожает | +50 | 0 |
| Друг | +30 | 0 |
| Приятель | +10 | 0 |
| Нейтрален | 0 | 0 |
| Недоволен | 0 | +10 |
| Враг | 0 | +30 |
| Ненавидит | 0 | +50 |

**Как меняются отношения:**

| Действие | Эффект |
|---|---|
| Внести закон, выгодный фракции | +10 |
| Внести закон, вредный фракции | -15 |
| Поддержать члена фракции | +5 |
| Унизить члена фракции | -10 |
| Назначить члена фракции | +10 |
| Игнорировать фракцию | -5 (каждый ход) |

### B03. Модель убеждения

**Формула:**

```
Шанс успеха = 50% 
            + clamp((Gratia - Gratia цели) × 2%, -30%, +30%)
            + (Отношения - 50) × 0.5%
            + (Fama - 50) × 0.3%
            + (Красноречие × 1%)
            + (Подкуп / 500) × 5%
            - (Сложность × 10%)
            + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..95%.

**Сложность:** 1 (лёгкая), 2 (средняя), 3 (сложная).

### B04. Модель подкупа

**Шанс успеха:**

```
Шанс = 70% 
      + (Сумма / 1000) × 5%
      - (Честность цели × 10%)
      + (Отношения - 50) × 0.3%
      + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..95%.

**Шанс скандала:**

```
Шанс скандала = 10% 
              + (Сумма / 5000) × 10%
              - (Astutia × 2%)
              - (Fama / 20)%
```

### B05. Модель выборов (cursus honorum)

**Формула:**

```
Шанс избрания = 30% 
              + (Gratia / 10) × 5%
              + (Fama / 10) × 3%
              + (Virtus × 3%)
              + (Поддержка фракций / 10) × 5%
              - (Конкуренты / 10) × 5%
              + (Деньги / 1000) × 2%
              + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..80%.

### B06. Модель изгнания / суда

**Изгнание (игрок изгоняет врага):**

```
Шанс = 30% 
      + (Gratia игрока - Gratia цели) × 1%
      + (Fama игрока - Fama цели) × 0.5%
      + (Поддержка фракций / 10) × 5%
      + (Компромат × 20%)
      + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..70%.

**Защита в суде (игрока обвиняют):**

```
Шанс = 50% 
      + (Gratia игрока - Gratia обвинителя) × 1%
      + (Fama игрока - 50) × 0.5%
      + (Astutia × 1%)
      + (Поддержка фракций / 10) × 5%
      + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..90%.

### B07. Модель заговора / переворота

**Формула:**

```
Шанс = 20% 
      + (Gratia / 10) × 5%
      + (Поддержка фракций / 10) × 5%
      + (Военная сила / 10) × 3%
      + (Astutia × 0.5%)
      + (Скрытность × 10%)
      - (Охрана цели / 10) × 5%
      + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..60%.

### B08. Модель кризиса Республики

**Факторы, повышающие кризис:**

| Фактор | Эффект |
|---|---|
| Гражданские войны | +10 за войну |
| Недовольство союзников | +1 за каждые 10% |
| Амбиции генералов | +2 за каждого (амбиции > 70) |
| Ослабление Сената | +1 за каждый закон |
| Внешние угрозы | +2 за крупное вторжение |
| Экономический кризис | +3 при инфляции > 30% |
| Смерть консула | +5 |

**Факторы, понижающие кризис:**

| Фактор | Эффект |
|---|---|
| Мир | -2 в год |
| Успешные реформы | -3 за реформу |
| Сильный Сенат | -1 за закон |
| Экономический рост | -2 при инфляции < 5% |

**Шкала кризиса:**

| Диапазон | Состояние | Эффект |
|---|---|---|
| 0–20 | Стабильность | Нет штрафов |
| 21–40 | Напряжение | +10% к заговорам |
| 41–60 | Кризис | +20% к заговорам, риск войны |
| 61–80 | Смута | Гражданская война возможна |
| 81–100 | Крах | Путь к Империи открыт |

**Пороги для Империи (в настройках сложности):** кризис > 80, Gratia > 70, армия > 50, поддержка армии > 60 (или фракции > 40).

## 13.5. Война (D01–D06)

### D01. Модель автобоя

**Сила армии:**

```
Сила = Численность × Качество × (1 + Virtus / 10) 
       × Модификатор ландшафта × Модификатор обороны
```

**Качество:**
```
Качество = 0.5 + (Снабжение / 100) × 0.5 + (Мораль / 100) × 0.5
```

**Модификатор ландшафта:** равнина 1.0, холмы 1.1 (оборона), горы 1.3, лес 1.15, болото 1.2.

**Модификатор обороны:** 1.0 + (Укрепления / 100) × 0.5.

**Исход:**

```
Соотношение = Сила игрока / (Сила игрока + Сила врага)
```

| Соотношение | Исход | Потери игрока | Риск командира |
|---|---|---|---|
| > 0.70 | Блестящая победа | 5–10% | 1% смерть, 3% ранение |
| 0.60–0.70 | Победа | 10–20% | 2% смерть, 5% ранение |
| 0.50–0.60 | Пирова победа | 20–30% | 5% смерть, 10% ранение |
| 0.40–0.50 | Ничья / отступление | 15–25% | 3% смерть, 8% ранение |
| 0.30–0.40 | Поражение | 25–40% | 7% смерть, 15% ранение, 5% плен |
| < 0.30 | Разгром | 40–60% | 10% смерть, 20% ранение, 8% плен |

**Модификаторы риска для командира:**

| Фактор | Эффект |
|---|---|
| Virtus 4–5 | -20% к риску |
| Virtus 1 | +30% к риску |
| Охрана | -30% к риску |
| Первые ряды | +50% к риску |
| Резерв | -20% к риску |
| Ранение в прошлой битве | +20% к риску |
| Возраст > 50 | +10% к смерти, +15% к ранению |

### D02. Модель осады

**Прогресс (блокада):**

```
Прогресс = (Численность / Гарнизон) × 0.5 
           × (1 - Укрепления / 100) 
           × (1 + Осадные машины × 0.5) 
           × (1 + Virtus / 10) 
           × Модификатор сезона 
           × Модификатор погоды 
           × Модификатор местности 
           × (1 - Снабжение_осаждающих_штраф) 
           × (1 + Снабжение_гарнизона_штраф) 
           × Случайный фактор (0.8–1.2)
```

**Порог падения:** 100.

**Модификаторы:** зима -30%, дождь -20%, снег -40%, горы -20%, болото -30%.

**Риски командира:**

| Действие | Смерть | Ранение | Бонус к прогрессу |
|---|---|---|---|
| Наблюдать из лагеря | 1% | 2% | +5% |
| На передовой | 5% | 10% | +15% |
| Лично вести штурм | 10% | 20% | +25% |
| Лично вести подкоп | 8% | 15% | +20% |

### D03. Модель лояльности и мятежа

**Лояльность армии:**

```
Лояльность = 50 
            + (Жалование × 20) 
            + (Победы × 5) 
            + (Харизма командира × 5) 
            + (Лояльность легата × 5) 
            - (Амбиции легата × 5) 
            - (Стресс армии / 10) 
            + (Слава командира / 10) 
            + (Присутствие командира × 10) 
            + (Личное участие командира × 5)
```

**Ограничение:** 0–100.

**Шанс мятежа:**

```
Шанс = (30 - Лояльность армии) × 2% 
      + (Честолюбие × 5%) 
      - (Лояльность легата × 5%) 
      + (Популярность легата / 10) × 3%
      - (Присутствие командира × 10%) 
      - (Личное участие командира × 5%)
```

**Ограничение:** 1%..60%.

### D04. Модель снабжения

**Формула:**

```
Снабжение = База (50)
            + (Инфраструктура_дороги / 100) × 20
            + (Инфраструктура_склады / 100) × 20
            + (Деньги / 1000) × 5
            + (Присутствие командира × 10)
            + (Личное участие командира × 5)
            - (Численность / 5000) × 10
            - (Война × 15)
            - (Зима × 20)
            - (Горы × 10)
            - (Болото × 15)
            + (Река × 10)
            + (Море × 15)
```

**Фураж для лошадей:** -Численность_кавалерии × 2.

**Голод:**

| Снабжение | Потери | Лояльность | Сила |
|---|---|---|---|
| 80–100 | 0% | — | — |
| 50–80 | 0% | — | -5% |
| 30–50 | 1% в ход | -5 | -10% |
| 10–30 | 5% в ход | -10 | -20% |
| 0–10 | 15% в ход | -20 | -50% |

### D05. Модель рекрутирования

**Формула:**

```
Рекруты = (Население × 10) × (Довольство / 100) × (1 + Воинственность × 0.5) 
          × (Деньги / 1000) × 0.1 
          × (1 + Присутствие командира × 0.2) 
          × (1 + Харизма командира / 10)
```

**Ограничение:** не более 10% населения провинции.

**Влияние на провинцию:**

| Эффект | Формула |
|---|---|
| Недовольство | -(Рекруты / 100) × 2 |
| Население | -(Рекруты / 100) × 1 |

### D06. Модель триумфа

**Формула:**

```
Шанс = 30% 
      + (Победы × 5%) 
      + (Fama / 10) × 3% 
      + (Gratia / 10) × 3% 
      + (Virtus × 3%) 
      + (Красноречие × 2%) 
      + (Поддержка фракций / 10) × 5% 
      - (Влияние врагов / 10) × 5% 
      + (Щедрость / 1000) × 2% 
      + (Личное участие × 10%)
```

**Ограничение:** 5%..90%.

**Влияние свойств:**

| Свойство | Эффект |
|---|---|
| Virtus 5 | +15% |

| Fama > 80 | +10% |

## 13.7. Информация (G01–G06)

### G01. Модель очереди сообщений

**Приоритет:**
```
Приоритет = (Срочность × 10) + (Важность × 5) + (Случайный фактор)
```

**Ограничение:** максимум 5 сообщений в очереди.

**Накопление «долгов»:**

| Ситуация | Последствие |
|---|---|
| Не прочитано 1 ход | Возвращается с пометкой |
| Не прочитано 2 хода | Разрешается автоматически (негативно) |
| Не прочитано 3 хода | Серьёзное последствие |
| Очередь > 5 | Новые сообщения теряются |

### G02. Модель срочности и достоверности

**Срочность (1–4):**
```
Срочность = Базовая срочность типа сообщения 
            + Модификатор контекста 
            + Модификатор отправителя
```

**Модификаторы:**
- Контекст: война +1, кризис +1, мир -1.
- Отправитель: друг +1, враг -1, официальное лицо +1.

**Достоверность (1–3):**
```
Достоверность = Базовая достоверность типа сообщения 
                + Модификатор отправителя 
                + Модификатор контекста 
                - Модификатор заинтересованности
```

**Модификаторы:**
- Отправитель: честный +1, лживый -1, неизвестный 0.
- Контекст: мир +1, война -1, кризис -1.
- Заинтересованность: если отправитель выигрывает от лжи -1.

### G03. Модель слухов

**Вероятность правды:**
```
Вероятность = Базовое доверие источника 
              + (Astutia игрока / 10) × 5% 
              - (Влияние врага / 10) × 10% 
              + Случайный фактор (-10%..+10%)
```

**Ограничение:** 5%..95%.

**Базовое доверие источников:**

| Источник | Базовое доверие |
|---|---|
| Форум | 30% |
| Таверны | 20% |
| Бани | 25% |
| Купцы | 40% |
| Слуги | 50% |
| Друзья | 60% |
| Враги | 10% |

### G04. Модель расследования

**Шанс успеха:**
```
Шанс = База (50%) 
       + (Astutia / 10) × 5% 
       + (Деньги / 500) × 5% 
       - (Сложность × 10%) 
       + Случайный фактор (-10%..+10%)
```

**Сложность:**

| Сложность | Что это |
|---|---|
| 1 | Простой слух |
| 2 | Семя |
| 3 | Заговор |
| 4 | Доказательства |

### G05. Модель семян событий

**Вероятность срабатывания:**
```
Вероятность = Базовая вероятность
              × (1 + Модификатор условий)
              × (1 + Модификатор игрока)
              × (1 + Модификатор мира)
              × (1 + Случайный фактор)
```

**Базовая вероятность:** 5–30% (зависит от типа семени).

**Срок жизни:**

| Тип семени | Срок жизни |
|---|---|
| Бунт | 10 ходов |
| Мятеж | 15 ходов |
| Заговор | 20 ходов |
| Скандал | 5 ходов |
| Болезнь | 8 ходов |
| Война | 25 ходов |

### G06. Модель LLM-диалогов

**Системный промпт:**
```
Ты — [имя NPC], [должность/роль]. Твой характер: [черты]. 
Твоё отношение к игроку: [слово]. Ты помнишь: [3-5 событий].
Текущий контекст: [событие].
Ответь на сообщение игрока. Верни JSON:
{
  "text": "твой ответ",
  "attitude_change": "улучшил/ухудшил/нейтрально",
  "information": "раскрыл/скрыл/нет",
  "promise": "да/нет"
}
```

**Обработка результата:**

| Поле | Категория | Эффект |
|---|---|---|
| attitude_change | улучшил | +10 отношения |
| | нейтрально | 0 |
| | ухудшил | -10 отношения |
| information | раскрыл | игрок получает слух |
| | скрыл | ничего |
| promise | да | обязательство NPC |
| | нет | — |

**Ограничения:**
- LLM не может менять состояние мира напрямую.
- LLM не может генерировать числа (только категории).
- LLM не может противоречить правилам игры.

## 13.8. Скрытые преступления: каналы, слои тайны, расследование

### 13.8.1. Слои тайны (4)

| Слой | Что скрыто | Сложность раскрытия |
|---|---|---|
| **1. Событие** | Что произошло | 1 |
| **2. Личности** | Кто сделал | 2 |
| **3. Мотив** | Почему | 3 |
| **4. Доказательства** | Чем подтвердить | 4 |

**Формула уровня знания:**
```
Уровень знания = Σ (Слой × Раскрыт)
```

**Ограничение:** 0–5 (0 — ничего, 5 — доказательство).

### 13.8.2. Каналы утечки тайны

| Канал | Вероятность | Задержка | Качество |
|---|---|---|---|
| **Рабы** | 5% | 2–5 ходов | Среднее (2) |
| **Клиенты** | 10% | 3–6 ходов | Среднее (2) |
| **Друзья** | 8% | 2–4 хода | Высокое (3) |
| **Род** | 3% | 4–8 ходов | Высокое (3) |
| **Женщины** | 6% | 2–4 хода | Высокое (3) |
| **Публичная жизнь** | 4% | 1–3 хода | Среднее (2) |

**Формула вероятности утечки (за ход):**
```
Вероятность = Базовая вероятность канала 
              × (1 + Модификатор скрытности) 
              × (1 - Модификатор защиты)
```

**Где:**
- `Модификатор скрытности` = 0.5, если убийцы скрывают (угрозы свидетелям).
- `Модификатор защиты` = 0.5, если тайна хорошо защищена (нет свидетелей).

### 13.8.3. Расследование (действия игрока)

| Действие | Стоимость | Шанс успеха |
|---|---|---|
| **Послать слугу** | 1 ОД + 100–500 | 50% |
| **Спросить друга** | 1 ОД | 40% |
| **Использовать Astutia** | 1 ОД | Astutia / 10 |
| **Нанять информатора** | 1 ОД + 500–2000 | 70% |

**Формула шанса успеха:**
```
Шанс = База (50%) 
       + (Astutia / 10) × 5% 
       + (Деньги / 500) × 5% 
       - (Сложность слоя × 10%) 
       + Случайный фактор (-10%..+10%)
```

**Сложность слоя:**

| Слой | Сложность |
|---|---|
| 1. Событие | 1 |
| 2. Личности | 2 |
| 3. Мотив | 3 |
| 4. Доказательства | 4 |

### 13.8.4. Пример: убийство Марка Сципиона

> **Тайна:** Корнелии убили Марка Сципиона.
> - Слой 1 (событие): раскрыт (слух).
> - Слой 2 (личности): раскрыт (вольноотпущенник).
> - Слой 3 (мотив): не раскрыт.
> - Слой 4 (доказательства): не раскрыт.
>
> **Уровень знания:** 2 (фрагмент).
>
> **Игрок расследует:** посылает слугу (1 ОД + 300).
> - Шанс = 50 + 30 (Astutia 60) + 3 (деньги) - 20 (сложность 2) + 3 = **66%**.
> - Успех: игрок узнаёт слой 3 (мотив).
> - **Уровень знания:** 3 (подозрение).

### 13.8.5. Крайние случаи

| Ситуация | Эффект |
|---|---|
| **Игрок знает, но не может доказать** | Может шантажировать (риск), но не может обвинить в суде |
| **Игрок обвиняет без доказательств** | -Gratia, -Fama, риск ответного иска |
| **Игрок молчит** | Тайна остаётся, но может выйти позже |
| **Тайна раскрыта** | Цель теряет Fama, Gratia, может быть изгнана |
